# PWS — аудит архива 1.4

Исследуется архив стандарта, по уточнению владельца; приложения и production не являются объектом этих измерений. Результат — улучшенный **1.4-rc4**, полный [аудит](AUDIT.md), [независимый review](INDEPENDENT-AUDIT.md) и [измерения валидаторов](RESULTS.json). Final/превосходство поведения ИИ не заявлены.

- `original-v1.4-rc3/` — 16 неизменённых файлов исходного ZIP.
- `reference-v1.3/` — девять файлов из замороженного Protocol 1.2, без checker.
- `candidate-v1.4-rc4/` — переносимый стандарт, те же 16 имён файлов.
- `test_checker.py` — 41 регрессионный тест, включая негативные записи.
- `compare_archives.py` / `PROTOCOL.md` — заранее зафиксированный 29-входный корпус, по три повтора.
- `SOURCE.json` — происхождение и исходные хеши; `RESULTS.initial.json` сохраняет первый прогон до review-исправлений.
- `verify_archive.py` — целостность исходников, обычные/оптимизированные тесты, сравнение, создание и проверка готового ZIP.

Из корня репозитория:

```sh
python3 benchmarks/project-workflow-standard/archive-1.4/verify_archive.py --output /tmp/pws-archive-evidence
```

Команда создаёт ZIP, SHA256SUMS.txt, BUILD.json, RESULTS.json и точные логи в заданном каталоге. Она не обращается к серверу и не публикует релиз. Защищённое чтение checker требует POSIX/Python 3.10+; новые фактические проверки выполнены на Python 3.12.14. Точный SHA и среда CI записываются отдельно.

В CI исходники и действие checkout/upload-artifact закреплены SHA; job имеет contents:read, без секретов и deploy. Старые результаты/методики за пределами этого трека не изменены. Проверка CRC-only — контроль целостности, а не AI Control. Все AI-метрики в этом треке не измерены.
