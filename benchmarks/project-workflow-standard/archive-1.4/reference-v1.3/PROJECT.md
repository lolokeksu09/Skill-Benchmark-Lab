## Указатели на источники

Укажи только существующие пути/ссылки: требования и решения, запуск/изолированная среда, сборка/CI, сопоставление L-уровней, текущий план/продолжение, выпуск/восстановление. Пока источники не указаны, агент ищет их в проекте.

Стек и команды берутся из исходников и конфигурации; HEAD/diff — из Git; результаты — из конкретного запуска. Их изменяемые значения сюда не копировать. Если такой источник отсутствует и сведения нужны для воспроизводимого запуска, запиши проверенную процедуру в документации проекта и оставь здесь ссылку.
