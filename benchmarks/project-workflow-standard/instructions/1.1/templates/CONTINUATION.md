# Продолжение работы

Образец для рабочей копии. Держи один текущий снимок; подробную историю оставляй в плане, коммитах, PR или журнале. Факты снабжай ссылкой на доказательство, секреты не переносить.

| Поле | Текущее состояние |
|---|---|
| Цель и существенные ограничения | Не заполнено |
| Версия | Ветка/сохранённый SHA и рабочий diff либо версия/хеш без Git не зафиксированы |
| Сохранено/доставлено | Не заполнено; различить локальный результат, коммит/PR и подтверждённую поставку |
| Проверки | Версия, среда/режим, команды или действия, результаты и ссылки не записаны |
| Ограничения и незавершённое | Не заполнено; указать недоступное и требуемое решение, если есть |
| Одно следующее действие | Не определено; назвать действие и ожидаемое подтверждение |

При возобновлении сверь снимок с кодом, Git/CI и артефактами. Старый чекбокс не делает завершённый релиз активной задачей. Финальный merge SHA может храниться в связанном PR: снимок не может содержать SHA собственного будущего коммита. Ранее данное разрешение учитывай в его границах.
