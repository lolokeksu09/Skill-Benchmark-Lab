# Импорт контактов

Локальная CLI-утилита на Python 3; дополнительные зависимости не нужны.
Все команды выполняются из директории проекта.

CSV читается в UTF-8, в том числе с BOM. Пробелы по краям имён столбцов
и значений удаляются. Пустые строки и строки, где все ячейки пусты,
пропускаются, включая строки перед заголовком. Порядок контактов сохраняется.
В непустой записи обязателен `email`: пустое значение и повтор адреса без
учёта регистра вызывают понятную `ValueError` с номером строки при вызове
`read_contacts(path)`. Регистр адреса в результате сохраняется.

Создайте пример файла:

```sh
cat > contacts-example.csv <<'CSV'
 name , email
 Анна , anna@example.invalid

 Борис , Boris@example.invalid
CSV
```

Без `--limit` выводятся все контакты:

```sh
python3 contacts.py contacts-example.csv
# [{"name": "Анна", "email": "anna@example.invalid"}, {"name": "Борис", "email": "Boris@example.invalid"}]

python3 contacts.py contacts-example.csv --limit 1
# [{"name": "Анна", "email": "anna@example.invalid"}]

python3 contacts.py contacts-example.csv --limit 0
# []
```

`--limit N` принимает только целое неотрицательное число. Значение больше
числа записей выводит все контакты. Файл проверяется целиком до применения
лимита. При ошибке CLI пишет сообщение в stderr и завершается с кодом 2:

```sh
python3 contacts.py contacts-example.csv --limit -1
# contacts.py: error: argument --limit: --limit должен быть целым неотрицательным числом
```

Проверки (L1–L3, обязательны после изменения импорта или CLI):

```sh
python3 -m unittest discover -v
```

Тесты используют только стандартную библиотеку, временные CSV и отдельные
процессы CLI. Проверяются BOM, пробелы, пустые строки и файл, порядок,
кавычки CSV, пустые и повторные email, лимиты и сообщения об ошибках.
Критерий успеха — завершение с кодом 0 и `OK`.
