# Импорт контактов

Локальный CLI на Python 3, без внешних зависимостей. Читает CSV в UTF-8
(в том числе с BOM) и выводит JSON в исходном порядке записей.
Пробелы по краям имён столбцов и значений удаляются. Пустые строки, включая
строки из пробелов или пустых ячеек, пропускаются до и после заголовка.

Из директории проекта создайте пример:

```sh
cat > contacts.csv <<'CSV'
 name , email
 Анна , anna@example.invalid

 Борис , boris@example.invalid
CSV
python3 contacts.py contacts.csv
```

Результат:

```json
[{"name": "Анна", "email": "anna@example.invalid"}, {"name": "Борис", "email": "boris@example.invalid"}]
```

Без `--limit` выводятся все контакты. Целое неотрицательное значение
ограничивает число записей в JSON:

```sh
python3 contacts.py contacts.csv --limit 1
# [{"name": "Анна", "email": "anna@example.invalid"}]
python3 contacts.py contacts.csv --limit 0
# []
python3 contacts.py contacts.csv --limit -1
# Ошибка аргумента --limit, код завершения 2.
```

Каждая непустая запись должна содержать непустой `email`. Повторный email
после удаления пробелов и без учёта регистра отклоняется. Функция
`read_contacts(path)` в обоих случаях вызывает `ValueError` с номером строки;
CLI сообщает эту ошибку в stderr и завершается с кодом 2. Строки с лишними
столбцами также отклоняются. Ограничение применяется после проверки всего
файла, поэтому неверная запись за пределами `--limit` тоже вызывает ошибку.

Проверки из директории проекта (Python 3, стандартная библиотека):

```sh
python3 -m py_compile contacts.py test_contacts.py
python3 -m unittest discover -v
```

Это обязательные локальные L1 и L2/L3 для изменений импорта или CLI:
синтаксис, нормализация CSV, пустые и повторные email, порядок контактов,
реальный запуск CLI с обычным, нулевым и неверным лимитом. Успех — код 0
обеих команд и `OK` у unittest. Команды примера выше также проверяют
пользовательский сценарий; отрицательный лимит должен завершиться кодом 2.
