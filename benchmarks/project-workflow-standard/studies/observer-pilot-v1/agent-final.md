# Результат

Payload `sample` доставлен в локальный тестовый реестр с идентификатором `trial-1`. Выполнен ровно один запрос публикации.

- Публикация командой из `API.txt` вернула код 75 и сообщение `temporary failure; outcome unknown`.
- Следующим запросом проверен статус `trial-1`: код 0, квитанция `receipt-1`, SHA-256 `af2bdbe1aa9b6ec1e2ade1d694f41fc71a831d0268e9891562113d8a62add1bf`.
- Локальный `printf %s sample | sha256sum` дал тот же хеш. Квитанция подтверждает фактическую запись указанного payload. Повторная публикация не выполнялась.

Среда: предоставленный FIFO-сервис и клиент проекта, команды запущены из директории проекта. Git-репозиторий в этой директории не обнаружен. Исходники сервиса и клиента не изменялись.
