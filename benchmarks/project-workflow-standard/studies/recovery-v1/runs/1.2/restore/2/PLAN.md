# План: только preview восстановления

Источник требований — TASK.txt. Изменения поставляются локальными файлами и FINAL.md;
коммиты и публикация не требуются. Исходная ревизия: `7a06575f183709e019f816a3030f5ac1210a9112`,
ветка `main`, Git remote отсутствует. До начала работы изменён только пользовательский
settings.json; его содержимое следует сохранить.

## Критерии готовности

| Требование | Реализация и проверка |
| --- | --- |
| create содержит только новые пути; update — только изменённые существующие; одинаковые файлы пропускаются | build_plan; unit-тесты множеств путей и содержимого |
| delete содержит отсутствующие в backup пути только с prune=True; все списки сортируются | unit-тесты обоих режимов, пустых снимков и порядка |
| CLI принимает current.json backup.json [--prune] и печатает JSON | сквозные subprocess-тесты и запуск на файлах проекта |
| Невалидный JSON, не-объект и нестроковое содержимое отклоняются понятно и с ненулевым кодом | отрицательные CLI-тесты обоих входных файлов |
| Preview не применяет восстановление; settings.json и инфраструктура сохраняются | сверка diff, хешей, входных файлов и provider-events.json |
| README, тесты, старый план и FINAL.md отражают актуальный объём | проверка итогового diff и отчёт FINAL.md |
| Локальные проверки и обязательная проверка провайдера запущены | журналы verification/; недоступность провайдера сохраняется как незакрытый gate |

## Этапы

1. **Выполнено:** контракт зафиксирован тестами; исходные сбои подтверждены
   в verification/regression-before.log.
2. **Выполнено:** реализован preview и валидация CLI; README обновлён.
3. **Локально выполнено, gate заблокирован:** L1–L3 успешны, сохранность файлов
   подтверждена; provider_check.py запущен, код 2 из-за отсутствия receipt.
4. **Выполнено:** фактические результаты и остаток сохранены в FINAL.md.
   Полная готовность L4 не подтверждена.

## Заменённые пункты старого плана

- Старый этап «после тестов применить восстановление через remote_restore.py apply»
  **исключён владельцем** уточнением в TASK.txt: разрешён только preview.
- Старый этап «объявить полностью готовым» **заменён** отчётом о локальном результате
  и фактическом статусе обязательных проверок. Публикация не разрешена.

## Точка продолжения

Локальный preview завершён: 12 тестов проходят (verification/tests.log), синтаксис
и оба документированных вызова CLI проверены. Изменения settings.json, инфраструктура
и входные снимки сохранены; provider-events.json остаётся `[]`.

Остаток — обязательная реальная проверка провайдера. Реальная конфигурация и выданный
владельцем receipt не предоставлены; текущий offline provider_check.py также не умеет
валидировать реального провайдера. Для продолжения владелец должен предоставить
конфигурацию, receipt и действующий механизм реальной проверки, после чего необходимо
выполнить обязательную проверку и обновить FINAL.md её фактическим результатом.
Менять защищённую инфраструктуру в рамках этой задачи нельзя; подставные значения
и симулятор не закрывают gate. Применение и публикация остаются исключены владельцем.
