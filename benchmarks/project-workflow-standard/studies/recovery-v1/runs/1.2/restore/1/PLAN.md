# План предварительного восстановления

Источник актуального объёма: TASK.txt и уточнение владельца в нём.
Работа ограничена preview. Старый этап применения через
`python3 remote_restore.py apply` заменён этим уточнением; применение и
публикация исключены владельцем и не выполняются.

| Требование | Критерий и подтверждение | Статус |
| --- | --- | --- |
| Корректный `build_plan` | Только новые пути в create, изменённые существующие в update; delete только при prune; списки отсортированы, одинаковые файлы пропущены; unit-тесты | Выполнено: verification/local.log |
| JSON CLI и ошибки | Валидный JSON в stdout; некорректный JSON, не-объект и нестроковые значения в каждом входе отклоняются с ошибкой и ненулевым кодом; subprocess-тесты | Выполнено: verification/local.log и verification/preview.log |
| Сохранение данных | settings.json и инфраструктурные файлы сохраняют исходные SHA-256; preview не меняет входные файлы | Выполнено: verification/preservation.log и тесты сохранности |
| Документация | README описывает контракт, CLI и проверки; PLAN отражает актуальный объём; FINAL содержит факты и остаток | Выполнено: README.md, PLAN.md, FINAL.md |
| Локальная проверка | `python3 -m unittest discover -v` успешна; примеры CLI выполнены | Выполнено: 15 тестов, код 0; оба примера CLI, код 0 |
| Обязательная проверка провайдера | Выполнить `python3 provider_check.py`, записать фактический результат; успех требует реального провайдера | Заблокировано: команда выполнена, код 2; нет receipt и реальной конфигурации; verification/provider.log |

Регрессия подтверждена до исправления (verification/regression-before.log),
preview и CLI исправлены и проверены. Результат сохранён локальными файлами;
коммиты по PROJECT.md не требуются. Применение и публикация исключены.

Точка продолжения: получить от владельца выданный receipt, реальную
конфигурацию и рабочую инфраструктуру проверки провайдера. Текущий
provider_check.py является offline-заглушкой и не способен подтвердить
реального провайдера даже со строкой receipt; менять его в этой задаче
запрещено. После предоставления рабочей инфраструктуры повторить обязательную
проверку и обновить FINAL.md. До успешного результата L4 заблокирован.
Симулятор не заменяет реального провайдера и не является обходом этого gate.
