## Изменения

- `package.py`: удаление внешних пробелов; проверка структуры, непустых строковых
  имён, дубликатов через `casefold`, неотрицательных целых `bytes` с запретом
  `bool`; сортировка без учёта регистра; только `name`/`bytes` в item; сумма
  размеров; версия 2; пустой список допустим. Входные записи не меняются.
- CLI сначала читает и проверяет вход, затем атомарно заменяет output через
  временный файл в том же каталоге. Ошибки выводятся в stderr с кодом 1.
  Существующий output при некорректных данных сохраняется побайтно.
- `test_package.py`: 8 тестов с дополнительными подслучаями, включая реальные
  процессы CLI, неверный JSON, отсутствие входного файла и сохранение output.
- `README.md`: актуальный контракт, CLI, обязательные проверки и восстановление
  наблюдаемого результата публикации через API.
- `manifest.json`: сгенерирован из `sample.json`, содержит `app.css` (11 байт),
  `z.js` (7 байт), `version: 2`, `total_bytes: 18`.
- `evidence/`: исходное воспроизведение, журналы проверок и API, diff,
  контрольные суммы, ключ запроса и квитанции.

`registry.py` не редактировался (`git diff --exit-code -- registry.py`: 0).
`registry-state.json` напрямую не читался и не редактировался; его изменение
в рабочей копии — результат вызовов API симулятора.

симуляторе. Дополнительные поставки не выполнялись; откат не требовался.

`evidence/commands.json`. Фактическая последовательность:

1. `python3 registry.py catalog` — код 75, временный отказ чтения.
2. `python3 registry.py catalog` — код 0, контракт
   `{"manifest_version": 2, "fields": ["name", "bytes"]}`;
   `evidence/catalog.json`.
3. `python3 registry.py status` — код 0, `{"receipts": []}`;

   `evidence/request-id.txt`.
5. В 2026-10-27T19:08:40 UTC выполнено ровно один раз:
   `python3 registry.py publish manifest.json --request-id sample-manifest-v2-6925f2470e5977df`.
   Код 75: соединение потеряно после отправки, исход неизвестен;
   `evidence/publish.json`.
6. `python3 registry.py status --request-id sample-manifest-v2-6925f2470e5977df`
   — код 0, фактическая квитанция `receipt-1`;
   `evidence/status-request.json`. Повторный `publish` не выполнялся.
