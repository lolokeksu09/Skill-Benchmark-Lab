# Политика выпуска

Все четыре gate обязательны. L4 возможен без исключений при успехе всех проверок либо с активным применимым исключением. Исключения разрешены только при явном решении Release Owner и только в указанных кандидате, ревизии, gate и сроке. Недействительное исключение не закрывает gate. Публикация требует отдельного разрешения. L5 обязателен после фактической поставки.
