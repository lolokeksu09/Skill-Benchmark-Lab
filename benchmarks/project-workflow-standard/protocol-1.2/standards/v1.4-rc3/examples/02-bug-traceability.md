# Пример 2 — исправление ошибки с требованием и регрессией (Full)

> Вымышленный сценарий. Приведённые записи — образец ожидаемого оформления, **не результаты реального прогона**.

**Симптом:** в форме настройки ошибочный ввод перезаписывает ранее сохранённое корректное значение. Настройка хранится во внешнем сервисе; исправление затрагивает обработчик формы и чтение при запуске, а работа передаётся между чатами. **Почему Full:** есть несколько зависимых сценариев, внешняя граница и передача контекста. Для аналогичной локальной ошибки с одной короткой проверкой достаточно Light без REQ-ID. **Защищённое поведение:** существующая корректная настройка сохраняется после перезапуска. Решение ведётся в одном плане/трекере.

| ID | Источник | Критерий и сценарий | Проверка | Состояние | Доказательство/остаток |
|---|---|---|---|---|---|
| REQ-007 | Обращение пользователя, п. 2 | Ввод ошибочной строки не меняет сохранённое значение, выводит понятную ошибку; повторный запуск сохраняет прежнее | L2: ошибка, повторная загрузка; L3: взаимодействие с внешним хранилищем | В работе | Ссылка на реальный тест и ревизию ещё не добавлена |

**Последовательность приёмки:**

1. На исходной версии воспроизвести потерю значения (либо назвать причину недоступности).
2. Исправить только нужную область, сохранив контракт хранения.
3. На точной новой ревизии проверить успешный ввод, ошибочный ввод, повторный запуск и ранее существовавшие настройки.
4. Записать отдельные результаты каждого сценария, ссылки на точные артефакты и среду (реальный backend либо mock, устройство либо эмулятор). **Mock подтверждает только моделируемую область**; обязательная L3-интеграция с внешним хранилищем остаётся непроверенной до запуска с реальной зависимостью.
5. Перевести `REQ-007` в «выполнено» **только если** критерий и защищённое поведение подтверждены; иначе оставить «частично» и точный остаток.

**Что нельзя делать:** считать успешную сборку проверкой исправления, ссылаться на произвольный CI без результата или объявлять физическое устройство протестированным после одного эмулятора.
