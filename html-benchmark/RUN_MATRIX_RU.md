# HTML Creation Benchmark — матрица запусков

## Замороженная база

- Ветка: bench/html-hard-base
- Задание: html-benchmark/TASK.md
- Изменяемый файл кандидата: только html-benchmark/index.html
- Проверки: 5 статических + 2 Chromium
- Merge до завершения всех запусков запрещён.

## Режимы

| Режим | Дополнительная обработка | Статус |
|---|---|---|
| Control | Нет | Baseline намеренно падает |
| P2P Original | Оригинальная предобработка P2P | Ожидает независимого запуска |
| P2P Improved | Улучшенная предобработка P2P | Ожидает независимого запуска |
| DDS 2.1.3 | Development & Design Skills 2.1.3 | Пройдено 7/7 |
| Combined | P2P Improved + DDS 2.1.3 | Ожидает независимого запуска |

## Общий промпт

Выполни задание из html-benchmark/TASK.md на замороженной базе bench/html-hard-base. Измени только разрешённый файл. Запусти статические и Chromium-проверки. Не редактируй тесты, workflow или benchmark-документы. Создай независимую ветку и PR без merge. В ответе укажи SHA базы, SHA результата, изменённые пути, результаты 5 статических и 2 Chromium-проверок, прочитанные навыки и ограничения.

## Правила сравнения

- Каждый режим стартует с одного и того же SHA базы.
- Нельзя переносить HTML или коммиты между режимами.
- Нельзя менять тесты после начала запуска режима.
- Ручная реализация не считается независимым запуском модели.
- В итоговый отчёт попадают только подтверждённые GitHub Actions результаты.
