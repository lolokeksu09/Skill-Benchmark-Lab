# Skill Benchmark Lab

An isolated, reproducible workspace for comparing prompt-design and engineering skill workflows.

**Planned variants:** no-skill control, P2P Original, P2P Improved, Development & Design Skills, and combined P2P + Development.

**Current status:** benchmark protocols and implementations are kept on topic branches. The project-workflow archive pilot is documented in [its own track](benchmarks/project-workflow-standard/README.md); results are limited to the recorded tasks and do not establish general improvement.

**Safety:** public repository. No credentials, private project code, personal data or unreviewed third-party distributions will be committed. AI execution and its potential costs require separate opt-in.

See the proposed v1 infrastructure in the setup pull request. NOX and WrCommunity remain unchanged.

## Project workflow archive

The [Project Workflow Standard track](benchmarks/project-workflow-standard/README.md) preserves the v1.1/v1.2 instruction snapshots, four local agent applications, input manifests, output checks and limitations. Deterministic CI replays saved code and rejects broken fixtures; it does not invoke an AI provider.

Historical V4–V6 benchmark branches and results remain separate and unchanged.
